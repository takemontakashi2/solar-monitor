# Solar Monitor 0.9.9

0.9.0以降の通信安定化と画面改善をまとめたリリースです。

## 画面の改善

- 買電をプラス、売電をマイナスで表示し、0の基準線を強調。現在値のカードにも売買方向を表示。
- 凡例をクリック・タップすると対象の線を太く最前面に表示し、他の線を薄く表示。再度選択すると解除。
- 5分平均／実測値の選択を保存し、再読み込み後も維持。
- 欠測があっても直近5分の取得済みの値で平均を計算。5分以内の欠測区間は破線で接続し、それより長い空白は接続しないよう改善。
- X軸を正時の目盛りに変更し、Y軸の目盛りを等間隔に整理。
- 機器の状態カードは正常時に折りたたみ。異常時や未取得・5分以上更新されていない場合は自動で展開。正常時も見出しから詳細を表示可能。
- 記録の読み出しに失敗した場合や時間がかかった場合に、画面上に状況を表示。

## 収集と保存の改善

- 旧形式の記録を読み出すためのインデックスを追加し、大きなDBでグラフAPIが長時間待たされる問題を修正。
- 固定情報の取得済み状態を接続先ごとに保存し、再起動後も保存値を使用。
- 明確に拒否された固定情報を通常取得から除外。タイムアウトだけでは除外せず、`-full-scan` で再確認可能。
- 初回の自動フルスキャンを廃止し、不要な問い合わせを削減。機器ごとに電力値を優先。
- 要求開始間隔を最低2秒、応答待ちを最大3秒に変更。返信元・要求番号・送受信オブジェクトを照合。
- 収集終了後に標準60秒の休止を確保。収集時間を含めた更新間隔は、実測で約1分50秒。
- 収集ごとの要求数・成功数・欠測項目・タイムアウト数・所要時間をログに記録。

## Windowsでの利用・更新

Windows x64版のZIPを展開し、PowerShellで起動してください。

```powershell
.\solar-monitor-0.9.9-windows-amd64.exe -v
.\solar-monitor-0.9.9-windows-amd64.exe
```

ブラウザで `http://localhost:8080/` を開きます。

更新時は旧版を停止し、`data/` をバックアップしてから、これまでと同じ作業フォルダーで新版を起動してください。設定と記録を引き継ぎ、必要なテーブル・インデックスを自動追加します。大きなDBでは初回起動に時間がかかる場合があります。ブラウザも再読み込みしてください。

ZIPにはREADMEと詳細ドキュメントを同梱しています。配布exeとZIPのSHA-256は `SHA256SUMS.txt` を参照してください。

## 確認状況と制限

- Goテスト・静的チェック、Windows x64ビルドを確認。
- JavaScriptの強調表示、状態カードの開閉、欠測処理、設定復元を検証。
- 利用者のWindows環境で0.9.9の表示改善を確認。
- 同じ通信処理を使う0.9.7の約30分の実機ログでは、初回の拒否判定後に413/416要求が成功（約99.3%）。長期間の安定性を保証するものではなく、単発の欠測は残ります。
- 対象実機はSHARP SUNVISTA JH-RWL8。他機種は未確認。
- 認証・TLSはなく、家庭内LANでの利用を想定しています。
