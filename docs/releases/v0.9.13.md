# Solar Monitor v0.9.13

## 変更点

- `-flush-interval 1h` などでDBへの保存間隔を指定できます。既定は従来どおり計測ごとに保存します。
- 保存待ちのデータもグラフ・カード・統計に表示します。計測の間隔や記録の細かさは変わりません。
- 通常終了時に未保存データを保存します。保存失敗時は保持して再試行し、バッファ上限時は先に保存、保存できなければ計測を一時停止します。
- 変更のない取得不可固定項目の一覧を毎回書き直す処理を削減しました。
- 前日・翌日にデータがない場合、その方向の日付移動ボタンを非表示にします。
- 次のタグ付き配布からWindows x64に加えてLinux ARMv6（Pi Zero / Zero W、32bit OS）・ARM64（Pi Zero 2 Wなどの64bit OS）の実行ファイルとtar.gzを作成します。

電源断・強制終了では未保存データが失われます。保存間隔を長くする場合はこの点を考慮してください。保存失敗が続くと指定間隔を超えるデータが未保存になります。

## 更新方法

アプリを停止し、dataフォルダーをバックアップして実行ファイルを差し替えます。同じ作業ディレクトリから起動すると設定と既存DBを引き継ぎます。ブラウザを再読み込みしてください。

```powershell
.\solar-monitor-0.9.13-windows-amd64.exe -flush-interval 1h
```

## 確認

Goのテスト・静的チェック、保存失敗時のロールバックと再試行、未保存データの表示、日付境界、通常停止時の保存を確認。Windows x64・Linux ARMv6・ARM64のクロスビルドを確認済み。WindowsとPiの実機動作は未確認です。
