# Solar Monitor 0.2.0

家庭用太陽光発電・蓄電池の値をECHONET Liteで取得し、SQLiteに記録してブラウザで表示する初回リリースです。

## 主な機能

- SHARP SUNVISTA JH-RWL8環境の発電・消費・買電/売電・蓄電池情報を取得。
- モニターの自動探索と接続先の保存。
- グラフの凡例、kW目盛り、時刻表示。
- 5分移動平均と実測値の切り替え。欠測は0として扱いません。
- 充電率などのカードに最後の取得値と取得時刻を表示。未更新時には「前回値」「更新待ち」を表示。
- `-v` / `--version` でバージョンとビルド元コミットを表示。

## Windowsでの利用

Windows x64向けです。zipを展開し、PowerShellで次を実行してください。

```powershell
.\solar-monitor-0.2.0-windows-amd64.exe -v
.\solar-monitor-0.2.0-windows-amd64.exe
```

ブラウザで `http://localhost:8080/` を開きます。タブレットからはサーバーPCのLAN内IPアドレスとポート8080を指定します。

既存環境ではサーバーを停止してexeを差し替え、これまでと同じ作業フォルダーから起動してください。`data/` は保持してください。起動前に停止状態の `data/` をバックアップしてください。既存DBには欠測を区別する列が自動追加されます。

`SHA256SUMS.txt` に配布ファイルのSHA-256を収録しています。PowerShellの `Get-FileHash <ファイル名> -Algorithm SHA256` で照合できます。
