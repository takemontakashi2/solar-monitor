# Solar Monitor 0.9.0

家庭用太陽光発電・蓄電池の記録とブラウザ表示を行うアプリです。SHARP SUNVISTA JH-RWL8環境を対象としています。

## 主な機能・変更

- ECHONET Liteでモニターを自動探索し、接続先を保存。
- 発電・消費・買電/売電・蓄電池情報を取得し、SQLiteへ記録。
- グラフに色付き凡例、kW目盛り、時刻を表示。5分移動平均と実測値を切り替え可能。
- 欠測と実際の0を区別し、欠測時や長い取得間隔では線を接続しないよう改善。
- 歯車で選択したカードを、起動直後・未取得・通信失敗時にも表示。未取得の値は `--`、前回値には取得時刻と更新状況を表示。
- `-v` / `--version` でバージョンとコミット情報を表示。
- READMEを利用者向けに整理し、開発手順と詳細設定を `docs/` に分離。配布ZIPにもドキュメントを同梱。

## Windowsでの起動

Windows x64向けのZIPを展開し、PowerShellで実行してください。

```powershell
.\solar-monitor-0.9.0-windows-amd64.exe -v
.\solar-monitor-0.9.0-windows-amd64.exe
```

ブラウザで `http://localhost:8080/` を開きます。詳しい操作は同梱のREADMEを参照してください。

更新時は稼働中のアプリを停止し、`data/` をバックアップしてからexeを差し替え、これまでと同じ作業フォルダーから起動してください。既存の設定と記録を引き継ぎます。古いDBには欠測判別用の列が自動追加されます。ブラウザも再読み込みしてください。

`SHA256SUMS.txt` でexeとZIPのSHA-256を照合できます。

## 確認状況・既知の制限

- Goテスト、静的チェック、グラフ処理とカード表示のJavaScript検証を実施。
- Windows x64向けにクロスビルド。Windows実機でのバージョン表示は旧0.2.0で確認済みですが、0.9.0の実機画面・長時間運転の確認は未実施です。
- 買電/売電のグラフは現在も絶対値表示で、売買方向の区別は今後の改善対象です。
- X軸は取得時刻に基づく表示です。正時に固定した目盛りは未対応です。
- グラフの滑らかさは実データで引き続き評価が必要です。
- 他機種の動作は未確認です。認証・TLSはなく、家庭内LANでの利用を想定しています。
